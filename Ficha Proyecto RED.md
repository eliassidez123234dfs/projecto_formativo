| **DESCRIPCIÓN DEL PROYECTO** |  |  |  |  |  |  |  |  |  |
| **Planteamiento del problema a resolver** La industria textil en Colombia enfrenta un alto índice de devoluciones (alrededor del 30% Según la Cámara Colombiana de Comercio Electrónico) en sus ventas online, ya que los clientes no pueden visualizar de manera realista cómo quedarán las prendas personalizadas antes de comprarlas. Para resolver esto, el Proyecto RED ofrece una plataforma web que integra un editor 3D en tiempo real con un marketplace. Esto permite a los usuarios crear diseños personalizados para comprarlos, mientras que otros pueden visualizar los diseños montados desde el lado de la empresa, personalizarlos y comprarlos. La empresa textil asociada se encarga de la producción y venta final. De este modo, RED reduce la incertidumbre en la compra, disminuye las devoluciones, genera un espacio de oportunidades para creadores y ayuda a la empresa a modernizar su canal de e-commerce con una propuesta innovadora y colaborativa |  |  |  |  |  |  |  |  |  |
| **Justificación** El comercio electrónico en Colombia ha experimentado una transformación significativa gracias a la adopción de tecnologías como APIs y visualización 3D, optimizando la experiencia del usuario y aumentando la conversión de ventas. La Cámara de Comercio de Medellín para Antioquia ha promovido la digitalización empresarial a través de su programa "Transformación Digital", apoyando a empresas locales en la adopción de tecnologías digitales. Aunque algunas tiendas virtuales han comenzado a integrar herramientas básicas de personalización, la adopción de tecnologías avanzadas como visualización 3D sigue siendo limitada, representando una oportunidad clara para la empresa RED. La industria textil colombiana enfrenta altos índices de devoluciones en e-commerce (alrededor del 30%, según la Cámara Colombiana de Comercio Electrónico) debido a la falta de opciones de personalización y visualización avanzada de prendas, lo que genera pérdidas económicas y baja satisfacción del cliente. El Proyecto RED propone una plataforma web que integra tecnologías 3D para permitir la personalización y visualización de prendas en 3D antes de la compra, lo que puede reducir devoluciones, mejorar la experiencia del usuario y modernizar el sector, aprovechando la creciente demanda de productos personalizados y alineándose con tendencias globales de digitalización y sostenibilidad.  |  |  |  |  |  |  |  |  |  |
| **Objetivo General** Desarrollar una plataforma web para la personalización y comercialización digital de prendas textiles, integrando tecnologías 3D en tiempo real que permitan la visualización interactiva de diseños, con el fin de reducir la incertidumbre en la compra y disminuir las devoluciones, facilitando un espacio de colaboración entre diseñadores y compradores. **Objetivos Específicos (PHVA): Planificar**: Definir los requerimientos y adquirir las herramientas tecnológicas necesarias para el desarrollo, integrando estándares ISO 9001, ISO 29119, ISO/IEC 27001 e ISO 14001 en la fase de diseño. **Hacer**: Desarrollar la base de datos, interfaces gráficas e integrar tecnologías 3D para la personalización de prendas, cumpliendo con los estándares WCAG 2.1 AA e ISO 9241 de accesibilidad y ergonomía de la interacción persona-sistema. **Verificar**: Evaluar la completitud de los requerimientos implementados, realizando pruebas de funcionalidad, seguridad y rendimiento según ISO/IEC 25010 y OWASP Top 10, garantizando un uptime óptimo. **Actuar**: Implementar la plataforma, capacitar a administradores, monitorizar el rendimiento y realizar mejoras continuas basadas en métricas y retroalimentación, aplicando PCI DSS para transacciones seguras.  |  |  |  |  |  |  |  |  |  |

Opera en Colombia con interfaces parcialmente traducidas y costos de envío elevados. Ha implementado algunas funciones de visualización pseudo-3D desde 2022, pero sin verdadera interactividad. **Gelato Estampados** (Noruega, red global): **fue fundada en 2007** por Henrik Müller-Hansen y alcanzó el estatus de unicornio (valoración de más de mil millones de dólares) en 2021\. Establecida en 2018, ha crecido en el mercado local pero con tecnología tradicional. **Iniciativas Relacionadas** La **Cámara de Comercio de Medellín para Antioquia** promueve la digitalización empresarial a través de su programa "Transformación Digital", apoyando a empresas textiles locales en la adopción de tecnologías digitales.
