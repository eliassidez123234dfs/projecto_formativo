Red Estampación: Plataforma web para personalización de camisetas con editor 3D

🎯 Propósito

Aplicación web modernizada tipo e-commerce que permite a clientes personalizar camisetas mediante un editor 3D en tiempo real, gestionar pedidos, y ofrecer una experiencia de compra completa con carrito de compras, checkout y pasarela de pago.

🛠️ Stack Tecnológico

Backend: Django + Django REST Framework + PostgreSQL + MongoDB + Redis. Frontend: React + Vite. 3D: Three.js. Pago: Wompi.

Django 6.0 DRF PostgreSQL MongoDB Redis React Vite Three.js Wompi Cloudinary

📐 Arquitectura

Backend monolítico modular (Django) con APIs REST separadas por módulo de negocio (usuarios, productos, carrito, pedidos, checkout). Frontend SPA con React Router. Persistencia híbrida: PostgreSQL para datos relacionales + MongoDB para diseños 3D y logs.

📋 Funcionalidades Clave

Registro/login con JWT, editor 3D de camisetas, carrito de compras con fusión anónimo→autenticado, checkout con Wompi, catálogo con filtros, panel admin completo, verificación por email, diseños guardados por usuarios.
